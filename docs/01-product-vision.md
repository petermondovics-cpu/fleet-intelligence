# Vision

Fleet Intelligence Platform is an AI-powered market intelligence and campaign automation platform for the fleet leasing industry.

The platform continuously collects leasing offers from multiple providers, normalizes the data into a unified model, stores historical market information and provides actionable insights for sales, marketing and management.

Instead of simply displaying offers, Fleet Intelligence helps companies answer questions such as:

- Which provider currently has the best offer?
- Which vehicle became cheaper today?
- Which offers should be promoted?
- Which campaign should receive additional budget?
- Which competitor changed pricing?

The platform acts as an intelligent decision support system for the fleet leasing business.
